# 发票识别与重命名工具

Windows 图形界面程序，用于识别 PDF 发票中的购买方名称、日期、金额和发票号码并批量重命名。

## 界面与操作流程

- 主界面按“添加文件 → 识别校对 → 重命名”排列，文件统计与操作按钮随当前状态更新；窗口缩小时优先保留列表空间。
- 双击购买方、金额、日期或发票号码可修改；补齐购买方和金额后可直接重命名。选中记录可查看目标文件名、完整路径和问题详情。
- 已识别或人工补齐的记录不会被再次识别覆盖；识别按钮只处理待识别和失败记录。
- 文件夹和压缩包在后台导入，重复文件自动跳过；右键菜单或 Delete 仅从列表移除，保留磁盘文件。
- 格式转换切换模式时保留兼容文件，默认输出到来源目录的“转换结果”文件夹，完成后可直接打开输出目录。
- 图片识别窗口批量管理照片，逐张对照原图与文字；切换照片保留修改，重新识别、移除或关闭前保护未复制、未保存的文字。

### 字段校验与重命名预览

购买方名称、金额为必填项。金额支持负数、规范的千分位和最多两位小数，保存时统一为两位小数；不自动四舍五入，也不把 OCR 的字母 O 猜成数字 0。
开票日期支持 `YYYYMMDD`、`YYYY-MM-DD`、斜杠、点号或中文年月日格式，并检查日期是否真实存在。发票号码按本工具支持的 8～20 位数字检查，保留前导零。
字段填写异常时，列表显示 `[异常]` 和复核说明。修正后重新校验；日期、号码留空仍允许省略，已填写但无效则不能参与重命名。这是本地格式检查，不查验发票真伪。

点击 **03 命名预览**，先查看每份文件的“原文件名 → 计划新文件名”、处理方式和跳过原因。
预览会同时检查磁盘文件和本批次计划的重名，提前分配 `_2`、`_3` 等序号。尚未识别、字段不合格、已重命名、名称无需变化或文件已移走的记录会跳过；全部跳过时不能确认执行。
可选择“返回修改”，确认前不会修改磁盘文件。确认后只执行预览中列出的目标名；如源文件或识别字段发生变化，或目标名称在预览后被其他文件占用，该项会停止并提示重新核对，不会临时更换名字或覆盖目标文件。

## 使用方法

```bash
python invoice_app.py
```

功能：
- 添加 PDF 文件或导入整个文件夹
- **添加压缩包（.zip/.rar/.7z），自动解压到桌面并导入 PDF**
- 预览识别结果（购买方名称、开票日期、金额、发票号码）
- 双击识别字段可手动修正
- 一键批量重命名
- 支持导出 CSV 识别记录，并在本次打开软件期间撤销上一次重命名
- 右键删除不需要的文件
- **格式转换：图片转 PDF、多图合并 PDF、PDF 转 PNG/JPG、图片互转、PDF 合并和逐页拆分**
- **批量图片识别文字：多选照片或导入文件夹，逐张校对、重试失败项、分别或合并导出 TXT**

## 图片识别文字

点击主界面的 **图片识别文字** → **添加照片**（可多选）或 **导入文件夹** → **开始批量识别**。
支持 JPG、PNG、WebP、BMP、单帧 TIFF，默认识别中文和英文，也可选择单一语言。
照片按列表顺序逐张识别，显示每项状态和总进度；单张识别失败不影响后续照片，无文字的结果单独标记。
窗口按“照片队列 / 原图预览 / 文字校对”分区；顶部统一导入、识别与批量导出，文字区显示字符数和待保存提示。
缩略预览会随窗口尺寸保持比例缩放，点击“放大”或双击图片可打开独立的大图查看窗口，不修改源文件。
列表自动跳过重复照片，可上移、下移调整合并顺序；选中照片查看预览并编辑文字，切换照片或追加照片不会丢失本窗口内的人工修改。
批量识别跳过已有文字，避免覆盖人工内容；“重新识别当前”可重识别选中照片，“仅重试失败项”只处理失败记录。重新识别失败时保留上次文字，并提示失败原因。

- **复制当前 / 保存当前 TXT**：处理正在查看的照片。
- **批量导出 → 分别保存 TXT**：每张有文字的照片输出一份 UTF-8 TXT，同名自动加序号，保留已有文件。
- **批量导出 → 合并保存 TXT / 复制合并文字**：按当前列表顺序合并，包含照片名称分隔，跳过空结果。重识别失败但保留了旧文字的记录会明确标注。

重新识别、移除照片或关闭窗口前，会检查所有受影响的未复制、未保存结果；仅切换查看不会弹出提示或丢弃结果。窗口关闭后不保留批次，请先复制或导出。

照片和识别过程都在本机完成，无需上传或调用付费接口。复用发票扫描件的 Tesseract 引擎和中文数据；源码运行需自行安装，便携版需使用内置 OCR 的压缩包。
请优先使用清晰、摆正的印刷文字照片。手写、模糊或复杂排版可能识别不准，结果需人工校对；该功能输出纯文本，不还原表格和原版式。

## 格式转换

点击主界面的 **格式转换（图片 / PDF）**，选择转换方式，添加文件并选择输出文件夹，点击“开始转换”。

| 功能 | 说明 |
| --- | --- |
| 图片转 PDF | 每张图片单独生成 PDF，或按列表顺序合并为一份多页 PDF |
| PDF 转图片 | 每页输出一张 PNG 或 JPG，150 DPI |
| 图片互转 | JPG、PNG、WebP、BMP、单帧 TIFF 可作为输入；输出 JPG、PNG、WebP、BMP |
| PDF 合并 | 按列表顺序合并多份 PDF，可用上移、下移调整 |
| PDF 拆分 | 每页生成独立 PDF |

转换在本机完成，原文件保留，已有同名输出自动加序号。透明图片转 JPG/BMP/PDF 时使用白底，自动校正手机照片的 EXIF 方向。
多帧 TIFF 等图片会提示先拆帧，避免只导出第一页。加密且需要密码的 PDF 会报告失败。
独立批量转换遇到坏文件会继续处理其他文件；合并遇错则不生成残缺合并文件。失败详情在窗口中显示。

勾选“完成后将生成的 PDF 加入发票列表”，即可继续预览识别和重命名；图片生成的 PDF 仍需 OCR。
Word/Excel 与 PDF 的互转不包含在本版功能内。转换后的 PDF 不保证保留原文档签名或交互表单功能。

以上转换使用项目已有的 Pillow 和 PDFium，无需新增转换软件。

> 支持 RAR 需安装：`pip install rarfile`；支持 7Z 需安装：`pip install py7zr`。ZIP 无需额外依赖。

### 打包为独立 .exe

1. 在 Windows 上安装 Python 3.9+
2. 双击运行 `build.bat`
3. 完成后在 `release/invoice-renamer-windows.zip` 找到便携包；完整解压后运行文件夹中的 `发票识别工具.exe`，保留 `_internal` 文件夹
4. 官方 Release 版会提供包含 OCR 引擎的压缩包；解压后双击 `.exe` 即可使用扫描件识别。

## 重命名规则

默认格式为：

`{开票日期}_{购买方名称}_{金额}_{发票号码后8位}.pdf`

识别不到日期或发票号码时会自动省略对应字段；重名自动加序号。

## OCR 支持（扫描件发票）

从 GitHub Release 下载的 Windows 压缩包已内置 Tesseract 和中文识别数据，**无需单独安装 Tesseract 或 Poppler**。

如果直接通过 `python invoice_app.py` 运行源码，扫描件识别仍需自行安装 Tesseract：

- Windows：https://github.com/UB-Mannheim/tesseract/wiki
- macOS：`brew install tesseract tesseract-lang`

程序使用内置的 PDFium 渲染扫描件，不再依赖 Poppler。
